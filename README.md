# 🐍 2D Snake Game in C++ (SDL2)

A modern 2D classic **Snake** game implemented from scratch in **C++** using the **SDL2** library. The project features a clean graphical interface, interactive HUD, score system, and High Score tracking.

---

## 🚀 Key Features

* **Classic Mechanics:** Smooth snake movement, random food generation, body growth, and collision detection (with walls and self).
* **Graphical Interface (HUD):** Real-time graphical rendering using SDL2, including current score and high score display.
* **Clean Architecture:** Modular code, efficiently organized for easy readability and a robust object-oriented/procedural structure.
* **Build System:** Natively configured for **CMake**, making it easy to run in environments like CLion or Visual Studio.

---

## 🛠️ Technologies Used

* **Language:** C++
* **Graphics Library:** SDL2 (Simple DirectMedia Layer)
* **Build System:** CMake
* **Recommended IDE:** JetBrains CLion / VS Code / Visual Studio

---

## 📦 Dependencies

To compile and run the game, make sure you have the following installed on your system:
* A **C++17** compatible compiler (GCC, Clang, or MSVC)
* **CMake** (version 3.15 or newer)
* **SDL2** library (e.g., `libsdl2-dev` on Ubuntu/Debian or installed via `vcpkg` / `brew`).
